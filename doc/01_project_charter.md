# 项目章程

## 1. 项目名称

DLT645-2007 电表模拟器桌面系统

## 2. 项目背景

本项目用于构建一个基于 Qt5 的桌面仿真工具，模拟符合 DLT645-2007 协议的电能表设备，支持通过串口或 TCP 与上位机、测试平台或主站系统进行通信。项目目标是为联调测试、协议验证、培训演示和离线调试提供可操作、可视化、可持久化的数据模拟环境。

## 3. 项目目标

- 提供串口和 TCP 两种通信方式。
- 提供电表实例创建、设备树管理和数据分类浏览能力。
- 支持电能量、最大需量、变量、事件、参数、冻结、负荷记录等数据模拟。
- 支持数据编辑、随机化、重置、导出和操作日志记录。
- 支持本地 SQLite 持久化，保证同一表地址数据可重复加载。

## 4. 项目范围

### 4.1 范围内

- Qt Widgets 桌面客户端
- DLT645 协议报文收发与解析
- 多连接、多电表管理
- 电表数据模型与本地持久化
- 操作日志与通信调试界面

### 4.2 范围外

- 云端集中管理平台
- Web 管理后台
- 多用户权限系统
- 分布式部署
- 自动远程升级

## 6. 关键里程碑

| 里程碑 | 目标 |
| --- | --- |
| M1 | 界面骨架、连接管理、设备树落地 |
| M2 | 电表模型与核心数据分类实现 |
| M3 | 协议控制、收发联调、日志联动 |
| M4 | SQLite 持久化和数据恢复 |
| M5 | 文档、测试、部署交付 |

## 7. 成功标准

- 能创建连接并成功打开/关闭串口或 TCP 通道。
- 能创建电表并按表地址恢复历史数据。
- 数据表中的编辑、随机化、重置操作能够同步写入数据库。
- 操作成功时能够在右侧操作日志区看到记录。
- 关键模块能完成构建并稳定启动。

## 8. 约束与假设

- 当前工程使用 Qt5 与 qmake，短期内不迁移到 CMake。
- 运行环境以 Windows 为主，Linux 为可扩展方向。
- 客户端为单机本地运行，数据库采用轻量级 SQLite。
- 部分项目管理类信息目前缺少真实客户签字和商务数据，后续需补录。
