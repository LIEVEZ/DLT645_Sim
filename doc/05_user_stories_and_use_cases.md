# 用户故事与用例

## 1. 用户角色

| 角色 | 描述 |
| --- | --- |
| 调试工程师 | 使用模拟器联调主站或采集程序 |
| 测试工程师 | 验证协议兼容性、边界值和异常场景 |
| 实施工程师 | 在现场快速搭建模拟环境 |
| 培训讲师 | 用于演示电表协议和数据结构 |

## 2. 用户故事

- 作为调试工程师，我希望快速新建一个串口连接和电表，这样我能马上开始联调。
- 作为测试工程师，我希望随机化当前分类数据，这样我能快速构造多组测试样本。
- 作为测试工程师，我希望修改后的数据能持久化保存，这样我重启程序后不需要重复录入。
- 作为实施工程师，我希望操作成功后日志区有记录，这样我能确认系统确实执行了保存。
- 作为培训讲师，我希望通过设备树按分类展示数据，这样学员更容易理解协议层次。

## 4. 典型用例说明

### UC-05 修改单个数据项

- 前置条件：已打开连接，已选择电表与数据分类
- 主流程：
  1. 用户双击数据值单元格
  2. 输入新值并确认
  3. 系统更新 `MeterModel`
  4. 系统保存到 SQLite
  5. 系统写入操作日志
- 结果：界面值、数据库值、日志状态保持一致

### UC-07 随机化当前数据列表

- 前置条件：当前分类列表存在数据项
- 主流程：
  1. 用户点击“随机化当前数据”
  2. 系统收集当前表格可见 DI 列表
  3. 系统只随机化该列表中的数据
  4. 系统同步聚合值
  5. 系统保存数据库并写日志
- 结果：只影响当前分类，不影响其他分类数据
