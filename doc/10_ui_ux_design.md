# UI/UX 设计说明

## 1. 设计目标

- 面向调试人员，强调高信息密度与快速操作
- 主要操作尽量在一屏内完成
- 数据浏览、日志观察、连接管理同时可见

## 2. 主界面结构

```text
菜单栏
工具栏
实时数据摘要条
-----------------------------------------
左：设备树   中：数据表    右：操作日志
-----------------------------------------
状态栏
```

## 3. 主要区域说明

### 3.1 左侧设备树

- 展示连接、电表和分类层级
- 提供搜索、刷新、展开、折叠
- 右键菜单承载连接和电表管理动作

### 3.2 中部数据表

- 显示当前分类的 DI 清单
- 提供搜索、重置、随机化所有数据、随机化当前数据、导出
- 支持双击编辑数值

### 3.3 右侧操作日志

- 显示系统、数据、通信相关日志
- 支持过滤、自动滚动、清空和导出

### 3.4 顶部工具栏

- 新建连接
- 新建电表
- 打开连接
- 关闭连接
- 通信交互

### 3.5 状态栏

- 当前连接状态
- 当前电表地址

## 4. 视觉风格

- 默认深色工业风主题
- 支持浅色主题切换
- 主色调偏深灰和蓝绿色高亮
- 适合长时间盯屏调试

## 5. 关键交互原则

- 先选设备树，再驱动中部内容
- 重要高频动作放在中部按钮区
- 数据修改后即时可见
- 操作结果通过日志确认，而不是隐藏执行

## 6. 体验优化建议

- 后续可增加写入成功的轻量 Toast
- 可增加当前分类统计信息和最近修改高亮
- 可增加数据库状态提示，例如“已同步/未同步”
