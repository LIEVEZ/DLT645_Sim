# 单元测试报告

## 1. 报告说明

当前项目尚未建立系统化自动单元测试工程，本报告用于记录当前代码基线下可识别的单元测试覆盖状态与建议补测范围。

## 2. 当前状态

| 项目 | 状态 |
| --- | --- |
| Qt Test 工程 | 未建立 |
| 自动单元测试脚本 | 未建立 |
| CI 中单元测试 | 未建立 |
| 手动功能验证 | 已进行部分验证 |

## 3. 已人工验证的关键点

- 主程序可构建
- 主界面可启动
- 数据库模块可初始化
- 电表地址分表持久化逻辑已接入主流程
- 随机化和数据变更会触发数据库保存

## 4. 建议优先补齐的单元测试

| 模块 | 建议测试点 |
| --- | --- |
| `MeterModel` | `setDataValue`、随机化、聚合同步、快照应用 |
| `MeterDataStore` | 序列化/反序列化、建表、加载、保存 |
| `ProtocolParser` | 报文解析与构帧 |
| `BCDHelper` | 格式转换与边界值 |
| `ChecksumHelper` | 校验和正确性 |

## 5. 当前结论

项目具备建立单元测试的基础，但当前不能给出量化覆盖率。后续建议先从 `Utils`、`MeterModel` 和 `MeterDataStore` 三个可独立测试模块开始补齐。
