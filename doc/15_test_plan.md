# 测试计划

## 1. 测试目标

验证电表模拟器在连接管理、数据展示、数据编辑、随机化、持久化、日志和通信联动方面满足需求。

## 2. 测试范围

### 2.1 包含

- 主界面与交互
- 设备树
- 数据表
- 电表模型
- SQLite 持久化
- 串口/TCP 打开关闭
- 操作日志显示

### 2.2 不包含

- 云端部署
- 多用户权限
- Web 接口

## 3. 测试级别

- 单元测试：建议补建
- 集成测试：主模块联动验证
- 系统测试：完整业务流程手工验证
- 回归测试：围绕随机化、持久化、日志进行

## 4. 测试环境

- Windows 10/11
- Qt 5.14.2 或兼容版本
- MinGW 7.3.0
- 本地 SQLite 文件系统

## 5. 测试重点

1. 表地址唯一性与恢复逻辑
2. 总值和子项同步关系
3. 数据保存后日志显示
4. 断开重启后的数据恢复
5. 导出与过滤功能

## 6. 进入准则

- 能完成构建
- 核心页面可打开
- 数据库初始化成功

## 7. 退出准则

- 关键用例通过率达到 95% 以上
- 阻塞级和严重级缺陷关闭
- 已知遗留问题有清单和规避说明
