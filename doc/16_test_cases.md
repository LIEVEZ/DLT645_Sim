## 2. 详细样例

### TC-06 编辑单个数据项

- 前置条件：已选择某块电表的某个数据分类
- 步骤：
  1. 双击“数据值”单元格
  2. 输入新值
  3. 按 Enter 确认
- 预期：
  - 当前单元格显示新值
  - SQLite 对应电表表被更新
  - 日志区出现“数据项已保存到数据库”消息

### TC-08 随机化当前数据

- 前置条件：中部表格已有数据
- 步骤：
  1. 点击“随机化当前数据”
  2. 观察当前表格
  3. 切换到其他分类对比
- 预期：
  - 当前分类数据发生变化
  - 非当前分类数据不被无关改写
  - 数据库保存成功
  - 日志显示批量保存信息

### TC-10 总需量同步

- 前置条件：存在正向/反向最大需量数据
- 步骤：
  1. 执行随机化
  2. 对比总最大需量与费率 1~4 最大需量
- 预期：
  - `0x01010000 = 0x01010100 + 0x01010200 + 0x01010300 + 0x01010400`
  - `0x01020000 = 0x01020100 + 0x01020200 + 0x01020300 + 0x01020400`
