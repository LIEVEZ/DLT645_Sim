# 缺陷报告

## 1. 报告说明

本报告记录当前阅读代码和已知实现中发现的缺陷、风险和技术债，供后续版本收敛使用。

## 2. 当前缺陷/风险清单

| 编号 | 级别 | 问题 | 状态 |
| --- | --- | --- | --- |
| DEF-01 | 中 | `MainWindow` 中存在历史遗留不可达代码段，影响可维护性 | 待修复 |
| DEF-02 | 中 | 自动化单元测试缺失，回归主要依赖手工验证 | 待规划 |
| DEF-03 | 中 | 部分文档仍混杂“规划态”和“现状态”描述 | 已通过本次文档整理缓解 |
| DEF-04 | 低 | 本地数据库未加密，适用于研发环境但不适合高安全场景 | 已知限制 |
| DEF-05 | 低 | Excel 导出当前为简化兼容实现，本质仍走 CSV 路径 | 已知限制 |

## 3. 已收敛问题

- 随机化时总电能与费率电能不同步的问题已收敛
- 瞬时总无功功率和总功率与分相不一致的问题已收敛
- 最大需量发生时间格式不一致的问题已收敛
- 数据库存储由共享表切换为按表地址分表的问题已收敛
- 保存数据库后未进入操作日志的问题已收敛

## 4. 建议修复顺序

1. 清理不可达代码和历史残留分支
2. 建立 `MeterModel` 与 `MeterDataStore` 单元测试
3. 补充协议互操作和导出验证
