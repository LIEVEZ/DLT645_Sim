# 运维手册

## 1. 日常运维内容

- 检查程序是否可正常启动
- 检查 `meter_data.db` 是否正常生成和更新
- 检查操作日志是否正常输出
- 检查通信连接是否能正常打开和关闭

## 2. 数据库维护

### 2.1 备份

- 关闭程序
- 复制 `meter_data.db` 到备份目录

### 2.2 恢复

- 关闭程序
- 用备份文件覆盖现有 `meter_data.db`
- 重新启动程序

## 3. 日志观察

- 重点关注数据库保存失败日志
- 重点关注连接打开失败日志
- 重点关注协议收发异常日志

## 4. 典型故障处理

| 故障 | 排查建议 |
| --- | --- |
| 程序无法启动 | 检查 Qt 运行库和平台插件 |
| 数据未保存 | 检查数据库文件权限与日志报错 |
| 电表数据未恢复 | 检查表地址是否一致、数据库分表是否存在 |
| 串口打不开 | 检查端口占用和参数配置 |
| TCP 连接失败 | 检查 IP、端口和网络连通性 |

## 5. 运维建议

- 重要演示环境建议定期备份数据库
- 测试前后保留数据库快照，便于复现问题
- 对正式交付环境建议建立版本发布和回滚记录
