# 用户操作手册

## 1. 启动程序

双击可执行文件启动，进入主界面后可以看到：

- 顶部菜单和工具栏
- 左侧设备树
- 中部数据表
- 右侧操作日志

## 2. 新建连接

1. 点击“新建连接”
2. 选择串口或 TCP
3. 填写连接别名和参数
4. 点击确认

## 3. 打开连接

1. 在左侧设备树选中连接
2. 点击“打开连接”或双击连接节点

## 4. 新建电表

1. 选中一个已连接上下文
2. 点击“新建电表”
3. 填写电表别名、地址、操作员代码、密码
4. 确认后电表会出现在设备树中

## 5. 查看数据

1. 在左侧设备树展开电表
2. 选择一个数据分类
3. 中部表格会显示该分类下的数据项

## 6. 修改数据

1. 双击“数据值”列
2. 输入新值
3. 确认后系统会自动保存

## 7. 随机化与重置

- 点击“随机化所有数据”可随机修改当前电表全部数据
- 点击“随机化当前数据”只随机修改当前列表
- 点击“重置所有数据”恢复默认值

## 8. 导出数据

点击“导出”，选择导出格式和位置即可。

## 9. 查看日志

右侧日志区可查看：

- 连接状态变化
- 数据修改
- 数据库保存结果
- 其他系统提示
