# 系统配置文档

## 1. 构建配置

工程文件：`Dlt645_Sim/Dlt645_Sim.pro`

关键配置：

- `CONFIG += c++17`
- `QT += core gui serialport network sql widgets`

## 2. 运行时配置项

### 2.1 连接配置

| 项 | 说明 |
| --- | --- |
| 连接类型 | 串口 / TCP |
| 串口号 | 例如 `COM1` |
| 波特率 | 例如 `2400/9600` |
| 数据位 | 5/6/7/8 |
| 停止位 | 1/1.5/2 |
| 校验位 | None/Odd/Even |
| TCP 地址 | 例如 `127.0.0.1` |
| TCP 端口 | 例如 `8080` |

### 2.2 电表配置

| 项 | 说明 |
| --- | --- |
| 电表别名 | 用户自定义名称 |
| 表地址 | 12 位地址字符串 |
| 操作员代码 | 8 位字符串 |
| 密码 | 8 位字符串 |
| 前导 FE | 是否启用 |

## 3. 数据库配置

- 数据库类型：SQLite
- 数据库文件：`meter_data.db`
- 表名规则：`meter_<address>`

## 4. 日志配置

- 日志通过 `Logger` 统一分发
- UI 中显示在右侧 `OperationLogWidget`
- 当前主要显示 `Info/Warning/Error`

## 5. 系统限制

- 当前主要面向单机使用
- 当前无独立配置中心
- 当前无账号权限控制
