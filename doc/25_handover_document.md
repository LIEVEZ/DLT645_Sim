## 3. 运行依赖

- Qt 5.x
- 对应编译器运行库
- Windows 文件写权限

## 4. 运维关注点

- 程序目录下 `meter_data.db` 需定期备份
- 升级版本前建议备份数据库和可执行文件
- 如需要清空历史数据，可在停机后替换数据库文件

## 5. 后续维护建议

1. 先阅读系统架构和技术实现文档
2. 修改数据模型时同步更新随机化与聚合逻辑
3. 修改数据库结构时补充迁移策略
4. 新增功能前补充测试用例
