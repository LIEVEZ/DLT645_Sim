## 📖 项目简介

DLT645_Sim 是一个完整实现 DLT645-2007 协议规范的电能表模拟器桌面应用，采用 MVVM 架构设计，支持通过 RS485 串口或 TCP 网络与网关或主站系统进行通信。

**核心价值**：
- 🔧 为电力自动化系统开发者提供全功能电表测试环境
- 🚀 支持多实例并行运行，模拟大规模电表部署场景
- 📊 提供完整的协议报文监视与日志记录能力
- 🎨 实现工业级深色主题，适合长时间专业使用

## ✨ 功能特性

### 核心功能

- ✅ **完整协议支持**：实现 DLT645-2007 七类数据项
  - 电能量（00 类）- 正反向有功/无功，组合电能
  - 最大需量及发生时间（01 类）
  - 变量（02 类）- 电压、电流、功率、功率因数等
  - 事件记录（03 类）- 失压、欠压、过压、失流、过流等
  - 参变量（04 类）- 电表参数配置
  - 冻结（05 类）- 定时冻结、瞬时冻结、约定冻结
  - 负荷记录（06 类）- 负荷曲线记录

- 🔌 **双模式通信**
  - RS485 串口通信（可配置波特率、数据位、校验位、停止位）
  - TCP 网络通信（支持作为 TCP 服务端）

- 🎯 **单相/三相表模拟**
  - 支持单相表和三相表配置
  - 单相表自动过滤 B/C 相数据项
  - 符合 DLT645-2007 标准规范

- 🔄 **实时数据模拟**
  - 电能量自动累加
  - 实时变量动态变化
  - 可配置刷新频率

- 📝 **可视化管理**
  - 设备树形结构展示
  - 数据表格编辑与查看
  - 实时操作日志记录
  - 完整报文监控与解析

- 💾 **数据管理**
  - 支持数据导出（CSV/JSON）
  - 配置文件持久化
  - 批量数据随机化
  - 一键重置功能

### 高级功能

- 🔍 **协议调试工具**
  - 通信报文实时捕获
  - 协议帧解析与查看
  - 查询帧生成器
  - 主站模拟查询

- ⚙️ **灵活配置**
  - 自定义电表地址（12 位 BCD 码）
  - 可配置密码和操作者代码
  - 事件记录开关控制
  - 费率配置支持

- 🎨 **用户体验**
  - 深色/浅色主题切换
  - 搜索与过滤功能
  - 快捷键支持
  - 右键菜单操作

## 🚀 快速开始

### 系统要求

- **操作系统**：Windows 10/11 或 Linux (Ubuntu 20.04+)
- **Qt 版本**：Qt 5.14.2+ (推荐 Qt 5.15.x)
- **编译器**：
  - Windows: MSVC 2019+ 或 MinGW 8.1+
  - Linux: GCC 7+ 或 Clang 10+
- **构建工具**：qmake

### 安装步骤

#### 1. 克隆项目

```bash
git clone https://github.com/LIEVEZ/DLT645_Sim.git
cd DLT645_Sim
```

#### 2. 构建项目

**使用 Qt Creator（推荐）**：
1. 打开 Qt Creator
2. 打开项目文件 `Dlt645_Sim/Dlt645_Sim.pro`
3. 配置构建套件（Kit）
4. 点击 "构建" 按钮

**使用命令行**：

```bash
# 创建构建目录（Shadow Build）
mkdir Build
cd Build

# 生成 Makefile
qmake ../Dlt645_Sim/Dlt645_Sim.pro

# 编译（Windows MinGW）
mingw32-make -j4

# 编译（Linux）
make -j4
```

#### 3. 运行程序

```bash
# Linux / MinGW
./debug/Dlt645_Sim

# Windows MSVC
debug\Dlt645_Sim.exe

# 或在 Qt Creator 中直接点击运行
```

## 📚 使用指南

### 基本使用流程

#### 1. 创建连接

点击工具栏 **"新建连接"** 按钮：

- **串口模式**：
  - 选择串口号（如 COM3）
  - 配置波特率（默认 2400）
  - 设置数据位、校验位、停止位
  
- **TCP 模式**：
  - 输入服务端 IP 地址
  - 配置服务端端口号

#### 2. 创建电表

在设备树中右键点击连接节点，选择 **"新建电表"**：

- 输入电表别名（如"电表1"）
- 配置通讯地址（12 位 BCD 码，如 123456789012）
- 设置操作者代码（8 位，默认 00000000）
- 设置电表密码（8 位，默认 00000000）
- 选择电表相型（单相表/三相表）
- 配置是否包含前导 FE

#### 3. 打开连接

右键点击连接节点，选择 **"打开连接"**，连接状态图标变为绿色 🟢

#### 4. 查看和编辑数据

- 在设备树中选择电表节点
- 展开数据分类（电能量、变量、事件记录等）
- 在数据表格中双击 **"数据值"** 列进行编辑
- 使用搜索框快速定位数据项

#### 5. 监控通信

点击菜单栏 **"视图 → 通信交互窗口"**：

- 实时查看收发报文（HEX 格式）
- 双击报文查看详细解析
- 支持过滤和导出

### 高级功能

#### 协议调试工具

- **帧解析**：菜单 → 工具 → 帧解析，粘贴报文 HEX 查看解析结果
- **查询帧生成**：菜单 → 工具 → 查询帧生成器，选择 DI 码生成查询帧
- **主站查询**：右键电表节点 → 主站查询，模拟主站发起读写操作

#### 数据管理

- **导出数据**：数据表格工具栏 → 导出按钮 → 选择格式（CSV/JSON）
- **随机化数据**：数据表格工具栏 → 随机化按钮 → 生成测试数据
- **重置数据**：数据表格工具栏 → 重置按钮 → 恢复默认值
- **批量新建电表**：连接右键菜单 → 批量新建电表

#### 配置持久化

- 程序自动保存配置到 `Build/dlt645_config.json`
- 下次启动自动加载上次的连接和电表配置
- 菜单 → 文件 → 导入/导出配置

### DLT645-2007 协议要点

**帧格式**：
```
FE FE FE FE | 68 | A0-A5 (地址) | 68 | C (控制码) | L (长度) | DATA | CS | 16
```

**控制码**：
- `0x11` - 读数据
- `0x14` - 写数据
- `0x13` - 读地址
- `0x91` - 正常应答
- `0xD4` - 写正常应答
- `0xC1` - 异常应答

**数据域加密**：
- 发送时：数据 + 33H
- 接收时：数据 - 33H

**DI 编码**：4 字节数据标识（如 `00 00 00 00` = 组合有功总电能）

### 编码规范

#### C++ 规范

- 使用 C++17 标准特性
- 遵循 Qt Coding Style
- 类名：大驼峰（PascalCase）
- 函数/变量：小驼峰（camelCase）
- 私有成员：`m_` 前缀
- 常量：`k` 前缀或全大写
- 一行最大 120 字符
- 使用 Qt 容器类（QList, QMap, QString）

#### 架构原则

- 视图层不直接持有业务逻辑
- 模型层通过信号通知视图更新
- 控制器负责协调模型与通信
- 工具类保持无状态、可复用
- 使用 QMutex 保护共享数据
- 优先使用智能指针管理资源

## 🐛 常见问题

### Q: 串口打开失败？

A: 
- 检查串口是否被其他程序占用
- 确认串口号是否正确
- Windows 需要安装 USB 转串口驱动
- Linux 需要将用户添加到 `dialout` 组：`sudo usermod -a -G dialout $USER`

### Q: 如何添加新的数据项？

A: 
1. 在 `MeterModel::initializeDefaultDataItems()` 中添加数据项定义
2. 在 `CategoryCatalog` 中更新分类映射
3. 重新编译运行

### Q: 如何自定义数据格式串？

A: 
- 格式串使用逗号分隔的 token 序列
- 支持的 token：`AA`（直接）、`xx`（除以10）、`F9`（正负号）、`.`（小数点）
- 示例：`F9,AA,AA,.,AA` → 正负号 + 4位整数 + 小数点 + 2位小数

### Q: 单相表和三相表有什么区别？

A:
- 单相表只支持 A 相数据项（B/C 相返回异常帧）
- 三相表支持 A/B/C 三相独立数据
- 事件记录：单相表只有 A 相事件，三相表有 A/B/C 三相事件
