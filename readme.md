## 1. 项目概述

### 1.1 项目背景

本项目旨在开发一个基于 Qt5 的工业级 DLT645-2007 协议电表模拟器，采用现代化 UI 设计和 MVVM 架构，实现界面与业务逻辑完全解耦。系统需完整实现协议规范中全部七类数据项的电能表功能模拟，支持通过 RS485 串口或 TCP 网络与网关或主站系统进行通信，用于测试、调试及教学演示。

### 1.2 核心功能

- ✅ 支持串口和 TCP 双模式通信
- ✅ 完整实现 DLT645-2007 协议七类数据项
- ✅ 实时数据显示与曲线图表
- ✅ 数据编辑与批量操作
- ✅ 通信报文监视与日志记录
- ✅ 多实例并行运行
- ✅ 工业级深色主题

### 1.3 技术栈

| 组件    | 技术选型                |
| ----- | ------------------- |
| 开发框架  | Qt 5.15+            |
| 编程语言  | C++11               |
| 构建系统  | qmake               |
| UI 设计 | Qt Widgets + .ui 文件 |
| 图表库   | Qt Charts           |
| 串口通信  | Qt SerialPort       |
| 网络通信  | QTcpSocket          |
| 数据格式  | JSON 配置             |

### 2.3 界面联动机制

**核心设计原则**：中部数据展示区的内容完全由左侧设备树的选中状态决定

**联动流程**：

1. 用户在左侧设备树中选择数据分类节点（如"电能量 → 当前"）
2. 中部数据表格自动加载并显示该分类下的所有数据项
3. 表格列包括：数据标识、名称、值、单位
4. 用户可在表格中查看、编辑、搜索数据
5. 双击数据值单元格可编辑，修改后实时同步到模型

**位置**：窗口最顶部

- **文件(F)**：新建、打开、保存、退出

### 3.2 顶部工具栏(MainToolBar)

**位置**：菜单栏下方

**按钮设计**：

| 按钮名称 | 图标  | 功能描述          | 快捷键    |
| ---- | --- | ------------- | ------ |
| 新建连接 | 🔗  | 打开串口/TCP配置对话框 | Ctrl+N |

#### 3.4.8 关键交互总结：

1. **空状态**：应用启动时设备树为空，提示用户新建连接
2. **连接优先**：必须先创建连接（Level 1），才能添加电表（Level 2）
3. **自动展开**：新建电表后自动展开数据分类（Level 3）
4. **多层级支持**：支持多个连接，每个连接下支持多个电表
5. **状态指示**：连接状态通过颜色圆点实时显示
6. **右键操作**：每个层级提供上下文相关的右键菜单
7. **配置持久化**：自动保存树形结构和展开状态

- 仅渲染可见行
- 预加载相邻数据
- 清理远离可见区域的数据

**数据清理**：

- 断开连接时清空临时数据
- 日志自动截断（保留最近10000条）
- 定期清理过期冻结数据

### 8.3 通信优化

**报文队列**：

- 请求队列管理，避免并发冲突
- 最小帧间隔控制（≥330ms）
- 超时重试机制（最多3次）

**批量读取**：

- 智能合并连续DI码的请求
- 减少通信次数，提高效率
